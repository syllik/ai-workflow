# Правила для AI-агентов

## Порядок чтения

Перед работой прочитайте:

1. `global/context.md`;
2. `global/workflow.md`;
3. `projects/<project>/context.md`;
4. context текущей задачи.

## Основные правила

- GPT-5.6 Sol — основной planning/architecture и research-агент.
- Luna xhigh — executor, coder и reviewer.
- Если существует `plan.md`, не меняйте архитектуру задачи без явной причины.
- Не используйте subagents и не тратьте токены на повторное исследование уже зафиксированных решений.
- Не создавайте лишнюю документацию.
- После задачи обновляйте canonical project context только при появлении устойчивых изменений.
- Никогда не сохраняйте secrets, credentials или содержимое `.env`.
- Пользовательские объяснения и документацию пишите на русском языке; технические имена оставляйте на английском там, где это естественно.
