# syllik profile context

## Repository

[`syllik/syllik`](https://github.com/syllik/syllik)

## Purpose

`syllik/syllik` is the public profile repository and canonical entry point for
purpose-first workspace navigation.

## Durable conventions

- Profile navigation describes approved repositories and their canonical local paths.
- Workspace documentation remains separate from project code and Git histories.
- New repository entries are added only by explicit user decision.

## Workflow constraints

- Do not include excluded repositories in profile navigation or workspace documentation.
- Keep repository links canonical and use the actual GitHub visibility and default branch.
- Never store credentials, tokens, private keys or `.env` contents.
